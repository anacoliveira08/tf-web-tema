## Wireframe
## Descrição
O projeto Cão Guru Pet Shop é um sistema web desenvolvido para apresentar os serviços de um pet shop, permitindo a visualização das informações do estabelecimento e o gerenciamento do conteúdo através de uma área administrativa.

## Funcionalidades
- Página inicial
- Página Quem Somos

- Página de Serviços
- Página de Contato
- Área administrativa
- Gerenciamento de serviços
- Gerenciamento de contatos
- Navegação entre páginas
